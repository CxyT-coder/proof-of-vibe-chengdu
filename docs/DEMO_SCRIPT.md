# Proof of Vibe · 60–90 秒演示稿

## 开始前

- 在 Windows 浏览器打开已部署的页面或 `http://localhost:3000`。
- Phantom 已选 Solana Devnet，钱包有足够支付交易费的测试 SOL。
- 提前确认 RPC 可读取签到墙；准备一句公开留言。
- 演示窗口只展示网页、钱包授权弹窗与 Explorer，不展示助记词、私钥或恢复界面。

## 台词与操作

| 时间     | 说什么                                                                                                           | 做什么                                                            |
| -------- | ---------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| 0–15 秒  | “这是 Proof of Vibe，成都链上签到。参加活动的人可以留下一句公开留言，并在 Solana 测试网上获得可验证的签到记录。” | 展示首页和公开签到墙，指出 Devnet 标识。                          |
| 15–30 秒 | “我用 Phantom 连接钱包。页面显示我的公开地址和测试币余额，私钥始终保留在钱包里。”                                | 连接 Phantom，展示地址和余额。                                    |
| 30–45 秒 | “昵称是‘成都 Builder’，留言是‘第一次 Solana，今天开始 Build’。先模拟，查看交易内容。”                            | 填表，点击“模拟签到交易”，展示摘要和模拟结果。                    |
| 45–60 秒 | “这笔交易写入公开 Memo，并用 0 SOL 自转携带活动标记。只消耗测试网手续费。现在由我在钱包里确认。”                 | 检查 Devnet 和金额，点击“确认并打开钱包”，手动确认 Phantom 弹窗。 |
| 60–75 秒 | “页面收到网络确认后给出交易链接。打开 Explorer，任何人都能核验这条记录。”                                        | 等待确认，点击 Explorer 链接，展示签名和 Memo。                   |
| 75–90 秒 | “其他人打开同一个页面，也能看到这条签到。下一步可以加入活动创建、完整历史索引和合约签到凭证。”                   | 返回页面，刷新签到墙，展示新增记录。                              |

如果网络等待超过演示时间，可说：“签名已经广播，仍在等待网络确认；页面会继续查询状态。”此时不要宣称签到成功。链上确认时间由网络和 RPC 决定。
